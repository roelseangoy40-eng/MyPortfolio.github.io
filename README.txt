PORTFOLIO WEBSITE FILES

All website files are together in this one folder:

- index.html       Main website page
- style.css        Website design and layout
- script.js        JavaScript functionality
- projects.json    Project information
- profile.jpg      Profile photo

IMPORTANT:
1. Keep all five files in the same folder.
2. Open this folder in VS Code.
3. Run index.html using Live Server.

Before publishing:
- Open script.js and replace GITHUB_USERNAME = "yourusername"
  with your actual GitHub username.
- In index.html, replace the placeholder GitHub and LinkedIn profile links
  with your real profile URLs.
- Add the project screenshot files referenced by projects.json
  (project1.png, project2.png, project3.png) if you want those images
  to appear in the project cards.
